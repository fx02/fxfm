Što je drugačije nego na Windowsu:
• Traka diskova umjesto c/d/l/m: / (Macintosh HD), ~ (home), zatim svaki montirani volumen iz /Volumes (USB, DMG, SMB share). Aktivne SFTP/FTP veze isto se pojavljuju kao "disk" (☁️ web-1).
• Meni (Files, Mark, Commands, Net, Show, Configuration, Start) nalazi se u gornjoj traci macOS-a, kao kod svake Mac aplikacije, a ne unutar prozora.
• Status umjesto Windows atributa (----, --h-) pokazuje Unix prava (drwxr-xr-x).
• Boje (moja pretpostavka): mape u [zagradama] bijele, skrivene datoteke sive, arhive narančasto-crvene, video/audio ljubičasto-plave, označene datoteke (Insert/Space) crvene. Sve se može podesiti.
